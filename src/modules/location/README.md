# Location module

Public Bangladesh divisions and districts reference data.

## HTTP

| Routes | Controller |
|--------|------------|
| `v1/locations/divisions` | `PublicLocationController` |
| `v1/locations/divisions/:id` | `PublicLocationController` |
| `v1/locations/districts` | `PublicLocationController` |
| `v1/locations/districts/:id` | `PublicLocationController` |

No cross-module exports (read-only public API).
